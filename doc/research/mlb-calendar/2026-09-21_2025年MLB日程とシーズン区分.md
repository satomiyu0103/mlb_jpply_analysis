# 2025年MLB日程とシーズン区分

- 調査日: 2026-09-21
- 関連: [analysis-plan-yamamoto-2025.md](../../agent/analysis-plan-yamamoto-2025.md) §3（期間・スプリット）

## 調査目的

2025年のレギュラーシーズンとポストシーズンの日付境界を固定し、Statcast や MLB Stats API でスプリット（レギュラー / ポスト / WS）を切るときの基準にする。
シーズン中の主要イベント（オールスター、トレードデッドライン等）も、分析の文脈説明用に併記する。

## 結論

2025年レギュラーシーズンは、東京シリーズ（3月18・19日）に続き、3月27日が全30球団の Opening Day、9月28日が最終日である。
ポストシーズンは9月30日の Wild Card から始まり、ワールドシリーズ第1戦は10月24日、必要時の第7戦は11月1日までである。
2025年ワールドシリーズはロサンゼルス・ドジャースがトロント・ブルージェイズを4勝3敗で下し、投手 MVP は山本由伸（LAD）である。

分析スプリットの第1案は次のとおりである。

| スプリット | 推奨フィルタ（第1案） | 備考 |
|------------|----------------------|------|
| 2025 レギュラー | `game_type == 'R'` かつ `game_date` が 2025-03-18 〜 2025-09-28 | 試合種別の詳細は [2026-09-21_Statcastの試合種別とスプリット.md](../other/2026-09-21_Statcastの試合種別とスプリット.md) |
| 2025 ポスト全体 | `game_type` が F, D, L, W のいずれか、または `game_date` ≥ 2025-09-30 | ラウンド別は `game_type` で分割 |
| 2025 WS のみ | `game_type == 'W'` | 試合日は下表の7日 |

## 分析への影響

[analysis-plan-yamamoto-2025.md](../../agent/analysis-plan-yamamoto-2025.md) の3スプリットに、日付と `game_type` の対応を載せた。
レギュラー順位の母集団は **2025 レギュラー先発** のため、ポストの球は `game_type != 'R'` で除外する。
WS 単独分析は `game_type == 'W'` が第一選択である。

`data/external/statcast/2025_regular.parquet` のようなファイル名は取得意図（レギュラー）を示すが、**中身の日付範囲は取得クエリ次第** である（下節）。

## ローカルデータとの照合

対象: `data/external/statcast/2025_regular.parquet`（読取のみ、2026-09-21 時点の取得分）

| 項目 | 値 |
|------|-----|
| 行数（1球） | 114,767 |
| `game_date` 最小 | 2025-04-01 |
| `game_date` 最大 | 2025-04-30 |
| `game_type` | R のみ（114,767 行） |
| 2025-03-18 / 03-19（東京） | 0 行 |

解釈: 当該 parquet は **2025年4月分のレギュラー（R）のみ** であり、シーズン全体や東京シリーズをカバーしていない。
シーズン境界の **カレンダー上の正** は本章の MLB 公式出典とし、フルレギュラー Statcast 取得後に同じ照合節を更新する。
