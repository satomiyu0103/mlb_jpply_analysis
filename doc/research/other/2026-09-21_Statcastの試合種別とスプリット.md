# Statcastの試合種別とスプリット

- 調査日: 2026-09-21
- 関連: [2026-09-21_2025年MLB日程とシーズン区分.md](../mlb-calendar/2026-09-21_2025年MLB日程とシーズン区分.md) · [analysis-plan-yamamoto-2025.md](../../agent/analysis-plan-yamamoto-2025.md)

## 調査目的

Baseball Savant / Statcast CSV の **game_type** 列が示す試合種別を整理し、本プロジェクトの分析スプリット（2025 レギュラー / ポスト / WS）へのフィルタ案を固定する。

## 結論

Savant 公式ドキュメントでは、**game_type** は1文字コードで試合種別を表す。
レギュラーシーズン分析の基本は **R**、ポストシーズンは **F**（Wild Card）、**D**（Division Series）、**L**（LCS）、**W**（World Series）で切る。
本プロジェクトの「2025 ポスト全体」は F, D, L, W の和集合とする。

列定義の正本（日本語訳）: [Statcast検索CSV列定義.md](../../agent/reference/Statcast検索CSV列定義.md)
英語の一次定義: Savant csv-docs（下記 URL）

## Savant 公式の game_type（Statcast Search CSV）

出典: [Statcast Search CSV Documentation](https://baseballsavant.mlb.com/csv-docs)（参照日 2026-09-21）

| コード | 意味（Savant 表記） |
|--------|---------------------|
| E | Exhibition |
| S | Spring Training |
| R | Regular Season |
| F | Wild Card |
| D | Divisional Series |
| L | League Championship Series |
| W | World Series |

Spring Training（S）と Exhibition（E）は、レギュラー・ポストの母集団から **除外** する。

## MLB Stats API / baseballr との差異（注記）

MLB Stats API や R パッケージ baseballr の `mlb_game_types()` には、Savant 表に無いコード（例: **P** = Playoffs 総称、**A** = All-Star Game）が載る。
Statcast CSV を polars で扱う本プロジェクトでは、**実データの `game_type` 列に現れる値** を優先する。
All-Star（A）がレギュラー取得に混ざる場合は、指標定義で含否を決める。

## 分析スプリットとの対応

| 本プロジェクトのスプリット | 推奨 polars 条件（第1案） | カレンダー上の目安 |
|---------------------------|---------------------------|-------------------|
| 2025 レギュラー | `game_type == 'R'` | 2025-03-18 〜 2025-09-28（[日程調査](../mlb-calendar/2026-09-21_2025年MLB日程とシーズン区分.md)） |
| 2025 ポスト（全ラウンド） | `game_type.is_in(['F','D','L','W'])` | 2025-09-30 以降 |
| 2025 WS のみ | `game_type == 'W'` | 2025-10-24 〜 2025-11-01 |

日付だけでポストを切る方法（`game_date >= 2025-09-30`）は、境界付近の誤包含を避けるため **game_type 併用** を推奨する。

## pybaseball 取得時の注意

`pybaseball.statcast(start_dt, end_dt)` は日付範囲指定であり、**game_type で自動分割されない**。
ファイル名（例: `2025_regular.parquet`）は利用者の命名規則であり、Savant が「regular」と保証するわけではない。
保存前に `game_type` の value_counts と `game_date` の min/max を確認する。

## ローカルデータでの確認（参考）

`data/external/statcast/2025_regular.parquet`（初回取得は 2026-09-21 時点の一部月のみ）では **game_type は R のみ**、日付は 2025-04-01 〜 2025-04-30 に限定されていた。のちフルシーズン再取得で上書き想定（ファイル名はスプリット固定）。
詳細は [日程調査](../mlb-calendar/2026-09-21_2025年MLB日程とシーズン区分.md) の「ローカルデータとの照合」を参照。

## 分析への影響

Notebook や `src/` でスプリット定数を置くときは、上表のコード集合をそのまま定数化できる。
FanGraphs の「Postseason」スプリットと Statcast の F/D/L/W を混同しない（結合キーと粒度が異なる）。
