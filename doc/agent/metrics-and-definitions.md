# 指標定義

分析で使用する主要指標の定義です。第 1 分析（山本由伸 2025）の正本は [analysis-plan-yamamoto-2025.md](analysis-plan-yamamoto-2025.md) と整合させる。

---

## 共通

### 分析スプリット

| 項目 | 内容 |
|------|------|
| 定義 | 集計対象の試合区分 |
| 分子 | — |
| 分母 | — |
| 除外条件 | スプリット間で混在させない |
| 日付の扱い | レギュラー / ポスト / WS は MLB スケジュールで境界を決める |
| 粒度 | 投手 × スプリット |
| 備考 | WS のみはサンプル小。順位母集団には含めない |

### 先発投手母集団（2025 レギュラー・順位用）

| 項目 | 内容 |
|------|------|
| 定義 | MLB 2025 レギュラーシーズンにおける順位比較の母集団 |
| 分子 | — |
| 分母 | — |
| 除外条件 | 救援のみ、規定回（qual）未達 |
| 日付の扱い | 2025 レギュラーシーズン |
| 粒度 | 投手 × シーズン |
| 備考 | MLB Stats API `playerPool=QUALIFIED` を優先。`ALL` 使用時は最低 IP（例: 100）を計画書脚注で明記 |

## 投手成績（MLB Stats API・レギュラー順位）

出典: `GET /api/v1/stats`（`group=pitching`, `stats=season`, `gameType=R`）。FanGraphs は本分析では使用しない。

### 勝率（Winning Percentage）

| 項目 | 内容 |
|------|------|
| 定義 | 投手の勝敗から求める勝率 |
| 分子 | 勝利数（W） |
| 分母 | 勝利数 + 敗戦数（W + L） |
| 除外条件 | ノーディシジョンは分母に含めない |
| 日付の扱い | 該当スプリット内の登板結果 |
| 粒度 | 投手 × スプリット |
| 備考 | **勝ち星数（W）は別指標**。WS 3 勝はカウントとして別列 |

### ERA

| 項目 | 内容 |
|------|------|
| 定義 | 自責点率 |
| 分子 | 自責点 |
| 分母 | 投球回 |
| 除外条件 | API 集計定義に従う |
| 日付の扱い | スプリット内 |
| 粒度 | 投手 × スプリット |
| 備考 | 出典: MLB Stats API `era` / `earnedRuns`。低いほど良い順位 |

### FIP（派生・簡易）

| 項目 | 内容 |
|------|------|
| 定義 | フィールドング独立防御率の **定数付き簡易式**（FanGraphs xFIP とは別） |
| 分子 | \(13 \times HR + 3 \times (BB + HBP) - 2 \times K\)（API の `homeRuns`, `baseOnBalls`, `hitByPitch`, `strikeOuts`） |
| 分母 | 投球回 `inningsPitched` |
| 除外条件 | IP = 0 は除外 |
| 日付の扱い | スプリット内 |
| 粒度 | 投手 × スプリット |
| 備考 | リーグ定数 \(c\) はシーズン固定値（実装時に 1 値を脚注）。**xFIP・fWAR は算出しない** |

### WHIP

| 項目 | 内容 |
|------|------|
| 定義 | 被出塁率 |
| 分子 | 安打 + 四球 |
| 分母 | 投球回 |
| 除外条件 | API 定義に従う |
| 日付の扱い | スプリット内 |
| 粒度 | 投手 × スプリット |
| 備考 | API `whip` または (H+BB)/IP。低いほど良い順位 |

### K%（三振率）

| 項目 | 内容 |
|------|------|
| 定義 | 対戦打者あたり三振の割合 |
| 分子 | `strikeOuts` |
| 分母 | `battersFaced`（BF） |
| 除外条件 | BF = 0 は除外 |
| 日付の扱い | スプリット内 |
| 粒度 | 投手 × スプリット |
| 備考 | FanGraphs の PA ベース K% と **数値が一致しない場合あり**（脚注）。高いほど良い順位 |

### BB%（四球率）

| 項目 | 内容 |
|------|------|
| 定義 | 対戦打者あたり四球の割合 |
| 分子 | `baseOnBalls`（必要なら `intentionalWalks` を脚注） |
| 分母 | `battersFaced` |
| 除外条件 | BF = 0 は除外 |
| 日付の扱い | スプリット内 |
| 粒度 | 投手 × スプリット |
| 備考 | 低いほど良い順位 |

### K-BB%

| 項目 | 内容 |
|------|------|
| 定義 | 三振率と四球率の差 |
| 分子 | K% − BB%（同一 BF ベースの API 派生値） |
| 分母 | — |
| 除外条件 | — |
| 日付の扱い | スプリット内 |
| 粒度 | 投手 × スプリット |
| 備考 | 高いほど良い順位 |

## Statcast 系（球種・投球内容）

### 球種別使用率

| 項目 | 内容 |
|------|------|
| 定義 | 当該球種のピッチ数の割合 |
| 分子 | 当該 `pitch_type`（または正規化後球種）のピッチ数 |
| 分母 | 当該投手・スプリットの全ピッチ数 |
| 除外条件 | `pitch_type` 欠損行は別集計または除外（脚注） |
| 日付の扱い | スプリット内 |
| 粒度 | 投手 × 球種 × スプリット |
| 備考 | Statcast / pybaseball |

### 球種別 Whiff%

| 項目 | 内容 |
|------|------|
| 定義 | スイングに対する空振りの割合 |
| 分子 | whiff（`description` 等で判定） |
| 分母 | スイング数 |
| 除外条件 | ボール・見送りのみのピッチは分母に含めない |
| 日付の扱い | スプリット内 |
| 粒度 | 投手 × 球種 × スプリット |
| 備考 | 高いほど「うちづらさ」の proxy |

### 球種別打席終了アウト率

| 項目 | 内容 |
|------|------|
| 定義 | 打席の **最後の 1 球** が当該球種である PA のうち、アウトになった PA の割合 |
| 分子 | 打席終了球が当該球種で、かつアウトとなった PA 数 |
| 分母 | 打席終了球が当該球種である PA 数 |
| 除外条件 | PA 終了の判定は Statcast `events` / `description` で実装時に固定 |
| 日付の扱い | スプリット内 |
| 粒度 | 投手 × 球種 × スプリット |
| 備考 | 通称「球種ごとのアウト率」。実装前に Notebook で判定ロジックを 1 例示す |

### リリース位置安定性（SD）

| 項目 | 内容 |
|------|------|
| 定義 | リリース点のばらつき（小さいほど安定） |
| 分子 | 球種ごとの `release_pos_x` または `release_pos_z` の標準偏差 |
| 分母 | — |
| 除外条件 | サンプル極小球種は脚注 |
| 日付の扱い | スプリット内 |
| 粒度 | 投手 × 球種 × スプリット |
| 備考 | 順位は **SD が小さいほど上位**（良い） |

| 項目 | 内容 |
|------|------|
| 定義 | 2025 ワールドシリーズにおける投手としての勝利数 |
| 分子 | 勝利登板数 |
| 分母 | — |
